# suzexAi

Local event-operations workspace for small organizing teams. It manages vendor fee reports, volunteers, committee work, and event details in one browser.

## Run locally

1. Install and run:

   ```powershell
   pnpm install
   pnpm dev
   ```

All data is stored in the browser's local storage. It is not shared between browsers or devices, and clearing site data will remove it. Receipt uploads are stored locally too, so keep them small.
